# 标签编辑器 — 用户手册
## 一、概述
标签编辑器用于设计和生成产品标签，支持**正面（中文）和反面（多语言翻译）**双面排版。通过 Excel 表头将正反面的文本元素关联起来，实现一键翻译。

## 二、基础操作
2.1 创建/打开模板
点击「新建模板」，输入模板名称、标签尺寸（宽×高）、顶缝、左右间距
勾选「需要翻译面」，选择翻译字典（如"巴拉"、"森马"）
进入编辑界面
2.2 添加元素到正面
从左侧面板拖动「文本」「图片」「表格」到正面画布
拖放后，反面会自动生成一个对应的占位元素
选中元素后，右侧面板可编辑其属性
2.3 设置 Excel 表头
选中文本元素，在右侧面板填写「Excel 表头」（如"成分"、"规格"）
正反面元素的表头名称相同才能关联翻译
三、翻译功能
3.1 核心概念
一个正面元素（key="成分"）
    ↙           ↘
反面元素1          反面元素2
langKeys=[英文,俄文]   langKeys=[阿语]
翻译由反面元素控制，正面只管编辑中文内容
相同表头的反面元素可以有多个，各自选择不同的翻译语言
翻译内容自动从正面相同表头的元素读取
3.2 操作步骤
正面：编辑文本内容，设置表头（如 key="成分"）
反面：选中对应表头的反面元素，右侧面板勾选翻译语言：
☑ 英文 → 自动翻译为英文
☑ 俄文 → 自动翻译为俄文
☑ 阿语 → 自动翻译为阿语（从右向左排列）
无需点击任何按钮，勾选即翻译
3.3 一对多翻译
同一正面元素可对应多个反面元素（按不同语言）：

点击反面元素列表右侧的 "+" 按钮，创建新的反面文本元素
设置与正面相同的表头（如 key="成分"）
选中新元素，勾选不同的语言（如只选阿语）
第一个反面元素显示英文+俄文，第二个只显示阿语
3.4 反面元素属性
反面元素拥有独立的样式属性（不随翻译自动改变）：

字号：翻译文本的字号
字体：可选 FZLTXIHJW、CenturyGothic、ArialMT、MiSans
粗体
字间距 / 行间距
四、导出 PDF
点击顶部工具栏「导出PDF」
系统自动生成包含正反面的标签 PDF
反面的翻译元素根据其 langKeys 配置生成对应语言的文本
五、快捷键 & 技巧
操作	方法
拖放元素
从左侧组件拖到画布
删除元素
右侧面板点击「删除元素」
调整顺序
拖拽元素左侧手柄上下移动
缩放画布
顶部工具栏调整缩放比例
返回列表
点击左上角「返回列表」
